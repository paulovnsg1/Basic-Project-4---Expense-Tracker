Expense Tracker

A simple command-line Expense Tracker developed in C++.

This project was created to practice object-oriented programming, vectors, functions, user input, and basic CRUD operations in C++.

Features
Add expenses
Display all registered expenses
Remove expenses by ID
Calculate the total number of expenses
Calculate the total amount spent
Automatically generate expense IDs
Technologies
C++
Standard Template Library (STL)
vector
Object-Oriented Programming
Project Structure
Expense-Tracker/
├── main.cpp
├── expense.cpp
├── expense.h
└── README.md

How to Run

Compile the project using:

g++ main.cpp expense.cpp -o expense_tracker


Then run:

./expense_tracker


On Windows:

.\expense_tracker.exe

       EXPENSE TRACKER
